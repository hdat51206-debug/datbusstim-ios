Thông tin ứng dụng

TikTok Boost hiện là ứng dụng web cài lên màn hình chính (PWA). Dữ liệu lịch sử được lưu cục bộ trên trình duyệt của thiết bị. Ứng dụng chưa kết nối API TikTok hay dịch vụ tăng tương tác.

iPhone: mở website bằng Safari → Chia sẻ → Thêm vào MH chính. Android: mở bằng Chrome → menu ⋮ → Cài đặt ứng dụng/Thêm vào màn hình chính.
